1) VEC-PRD-VPC-TOMCAT-PRI-2A Was 전용 서버 생성

이름은 VEC-PRD-VPC-TOMCAT-PRI-2A로 입력
VEC-PRD-VPC-TOMCAT-PRI-2A
YAML
복사
AMI는 Ubuntu Server 22.04 LTS(HVM), SSD Volume Type으로 지정
인스턴스 유형은 기본 Default인 t3.micro 사용
키 페어는 아까 생성한 powermvp.pem 키로 지정
[네트워크 설정]에서
[VPC]는 이전에 생성한 ‘VEC-PRD-VPC’로 지정
[서브넷]은 ‘VEC-PRD-VPC-TOMCAT-PRI-2A’로 지정
[퍼블릭 IP 자동 할당]은 비활성화로 변경

[고급 네트워크 구성] 클릭
[기본 IP]를 ‘10.250.2.240’으로 입력 후 [인스턴스 시작] 클릭
